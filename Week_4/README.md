# ❤️ Heart Disease Prediction - Week 4

## 📌 Project Overview

This project is part of the AI/ML Internship Week 4 assignment. It builds upon the Week 3 Heart Disease Prediction project by introducing advanced machine learning techniques such as model pipelines, cross-validation, hyperparameter tuning, feature importance analysis, and model persistence.

The objective is to build a robust and optimized machine learning pipeline capable of predicting the presence of heart disease using patient clinical data.

---

## 🎯 Objectives

- Build reusable machine learning pipelines
- Apply data preprocessing using ColumnTransformer
- Train multiple machine learning models
- Evaluate models using Cross Validation
- Optimize model performance using GridSearchCV
- Compare baseline and optimized models
- Analyze feature importance
- Save the best trained model for future use
